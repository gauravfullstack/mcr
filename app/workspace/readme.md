Functional Requirements

1. User should be able to add, remove, edit and mark todo as completed.
2. Simple UI including Input, Add button, List of todos and each todo have edit and remove button.
3. If there is no todo then show No Todo Text.
4. When user click on edit todo, the input box should pre filled the text of that selected todo and allows user to change or modify the text using the same input and button.
5. Make sure keyword accebility also works on click of Enter button, it should add the todo.
6. Persist todos in localstorage so it will not loose while reloading the page.


Data Model

1. Todo: {id: string, text: string, isCompleted: boolean};
