 Machine Coding Components

B1. Basic interactive components
Build a counter with increment, decrement, reset, and a step input.
Build a todo app with add, edit, delete, mark complete, and filter by All, Active, and Completed.
Build a star rating component with hover preview and keyboard support.
Build an accordion where only one panel can be open at a time, and one where several can be open.
Build a tabs component where the active tab is kept in the URL query string.

B2. Forms
Build a multi-step form (three steps) with validation on each step and a summary at the end.
Build a form with dynamic fields, where the user can add and remove phone numbers.
Build a login form that shows field-level errors and disables the submit button while the request is in progress.
Build a file upload component that shows a preview and a progress bar.

B3. Data fetching and lists
Build a user list that fetches from an API and shows loading, error, empty, and success states.
Build a product listing with search (debounced), category filter, and sort by price.
Build an infinite scroll list that loads the next page when the user reaches the bottom.
Build a paginated table with page size selection and previous / next controls.
Build an autocomplete input that fetches suggestions, cancels stale requests, and supports keyboard navigation.

B4. Overlays and UI behaviour
Build a modal that traps focus, closes on Escape, and closes on an outside click.
Build a dropdown with a searchable list that closes when you click outside it.
Build a toast notification system where toasts stack and disappear after a set time.
Build a tooltip that positions itself above or below the target element depending on available space.
Build a sidebar menu with nested items that expand and collapse.

B5. Stateful and interactive widgets
Build a shopping cart with add, remove, quantity change, and a total that updates correctly.
Build a countdown timer with start, pause, resume, and reset.
Build a drag-and-drop Kanban board with three columns and moving cards between them.
Build a calendar component that shows the current month and lets the user select a date.
Build a theme switcher that stores the choice in localStorage and applies it on page load.

B6. Custom hooks
Write a useFetch(url) hook that returns data, loading, and error, and cancels the request on unmount.
Write a useDebounce(value, delay) hook.
Write a useLocalStorage(key, initialValue) hook that stays in sync across tabs.
Write a usePrevious(value) hook.
Write a useOnClickOutside(ref, handler) hook.
Write a useInterval(callback, delay) hook that handles the latest callback correctly.

B7. Recursive UI

Build a nested comments section where each comment can have replies to any depth, with a “Reply” button that opens an input under that comment.
Build a file explorer that shows folders and files in a nested tree, where clicking a folder expands or collapses it.

B8. Data tables
Build a data table that sorts by any column in ascending or descending order, and clicking the same header a third time clears the sort.
Build a data table with pagination, where changing the page size or the sort keeps the user on a valid page.

B9. Additional Interactive Components
Build an OTP input component with auto-focus, backspace navigation, and automatic submission when all digits are entered.
Build a Tic-Tac-Toe game with turn management, winner detection, and a reset option.
Build a traffic light component that cycles through red, yellow, and green lights automatically, and a progress bar component that supports configurable progress and animation.
Build a tag input component that allows users to add and remove tags using Enter, Backspace, and a remove button.
